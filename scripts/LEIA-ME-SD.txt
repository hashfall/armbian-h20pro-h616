ARMBIAN H20 PRO (H616) — BOOT PELO CARTAO SD
============================================================

Este cartao inicia o Armbian DIRETO DO SD. O eMMC nao e tocado.
O objetivo e HDMI, Ethernet 100M, Wi-Fi/BT e USB funcionando.

ANTES DE BOOTAR
- Se existir /boot/emmc-install/enabled neste cartao, APAGUE.
  Esse marcador pertence ao instalador antigo de eMMC, que apaga o eMMC.
- Nao crie /boot/emmc-install/allow-emmc-install.

LOGIN
- usuario: glenda
- senha:   glenda
- root:    glenda
- console UART: ttyS0, 115200 8N1 (getty habilitado)

EXPANDIR O ROOTFS DO SD
    sudo ./scripts/expand-rootfs.sh
ou, se o helper ja estiver instalado:
    sudo /usr/local/sbin/expand-rootfs.sh

CONFIRMAR QUE ESTA NO SD
    findmnt -no SOURCE /
Esperado: /dev/mmcblk0p1 (SD).
Se aparecer /dev/mmcblk2p1, voce esta no eMMC: pare.

HDMI
- Aplicar os patches 0005 e 0006 no build do kernel e atualizar o SD.
- Sem EDID, testar com: video=HDMI-A-1:1024x768@60
- Diagnostico: dmesg | grep -Ei 'hdmi|phy'

REDE
- Ethernet: gmac1 / AC300 (driver no kernel 6.18; validar DTS).
- Wi-Fi/BT: UWE5622/AW859A (driver + firmware wcnmodem.bin + DTS).

eMMC (LEGADO)
- scripts/emmc-install.sh so roda com allow-emmc-install e APAGA o eMMC.
- Nao use no fluxo normal. O projeto atual e SD-only.
